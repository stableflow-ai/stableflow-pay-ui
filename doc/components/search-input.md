# search-input

Search field with a clear button.

Import `@stableflow/pay-ui/search-input`.

```ts
import { SearchInput } from "@stableflow/pay-ui/search-input";
```

| Prop | Role |
| --- | --- |
| `value`, `onChange` | Controlled text. |
| `inputClassName` | Merged onto the input after the default field classes. |
| `iconClassName` | Merged onto the leading search icon after `size-3.5`. |
